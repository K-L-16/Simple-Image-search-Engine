# Simple-Image-Search-Engine

## This is a image search application built using the Unsplash API, user can search for images by keyword.

* Create a weather app with HTML, CSS, and Vanilla JavaScript.
* Fetches data from Unsplash API by keyword.
* A good example of practicing web front-end basics.

## Here is the link to the project/demo


## How to download this demo/code

1. Clone this repository
   
    `git clone https://github.com/K-L-16/Simple-Image-search-Engine.git`
   
    `cd Simple-Image-search-Engine`

3. Get an API key
   
   Visit Unsplash Developers

   Sign up and copy your Access Key

3. Add your API key

   In script.js replace placeholder value: `const accessKey  = "YOUR_API_KEY_HERE";`

4. Simply open index.html in your browser
